PUBLISHED EVIDENCE DOCUMENTS
============================

Place only evidence files approved for accreditor/external viewing in this folder.

Recommended file naming pattern:
BPSU-CBA-L4-AI-0001-v1.pdf
BPSU-CBA-L4-AII-0007-v2.pdf

Then set the matching fileUrl in:
assets/data/portal-data.js

Example:
fileUrl: "documents/BPSU-CBA-L4-AI-0001-v1.pdf"

IMPORTANT:
Do not place confidential, draft, personally sensitive, or internal review documents here.
Everything inside a publicly hosted static site should be treated as externally accessible.
