# Publication Checklist

Before adding an evidence file to the public/static accreditation portal, confirm:

- [ ] The document has completed the internal review and approval process.
- [ ] The version being published is the final/current approved version.
- [ ] The document contains no information that should remain internal or confidential.
- [ ] Personal information has been reviewed and redacted where required by institutional policy.
- [ ] The document code, version, Area, and criterion/indicator metadata are correct.
- [ ] The filename is stable and descriptive.
- [ ] The file opens correctly in a standard browser or office/PDF viewer.
- [ ] The portal record points to the correct file.
- [ ] An authorized accreditation lead has approved external publication.
