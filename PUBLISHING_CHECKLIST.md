# Direct Publication Checklist

Before selecting **Publish Directly to Evidence Library**, verify that:

- the uploaded file is the exact final version;
- the program (BSA or BSBA), Area, criterion, document type, and academic year are correct;
- the reviewer has approved the document;
- confidential, personal, and restricted information has been reviewed;
- the document is suitable for accreditor or public viewing;
- the publication note records any redaction or scope decision.

After publication:

- open the document from the public Evidence Library;
- confirm that the file loads and its metadata is correct;
- use **Remove from Evidence Library** immediately if a problem is discovered.

No GitHub token, transfer package, or manual JSON merge is required.
