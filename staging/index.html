Transfer to BPSU AACCUP Portal

Two publication methods

Use the transfer package for the safest manual handoff, or use Direct GitHub Publish with a fine-grained token limited to the portal repository.

Method A · Recommended

Transfer Package

Downloads a ZIP containing approved files, evidence metadata, a CSV manifest, and instructions. No credential is required.

Method B · Optional

Direct GitHub Publish

Uploads selected Ready-to-Publish files and updates evidence.json in the public portal repository. The token is never saved by this application.

Direct GitHub Publish

Use only a fine-grained token restricted to BPSU-AACCUP-PORTAL with repository Contents read/write. The token remains only in this page's memory and is cleared on refresh.

Operational guide

Recommended accreditation workflow

1

Upload locally

Choose BSA or BSBA, Area I–V, enter controlled metadata, and attach the evidence file.

2

Review

Move the record to For Review. Open the file and verify the exact version to be released.

3

Clear for publication

Use Mark Ready only after privacy, confidentiality, and publication checks are complete.

4

Transfer

Export a transfer ZIP or use Direct GitHub Publish for selected Ready-to-Publish evidence.

5

Verify public portal

Confirm the correct program, Area, metadata, and file can be opened from GitHub Pages.

6

Maintain local record

The staging portal records the item as Published and keeps the portal URL and publication timestamp locally.

Local Workspace Backup

Because this is a static/local staging portal, browser data can be lost if site storage is cleared. Create periodic backup packages.
