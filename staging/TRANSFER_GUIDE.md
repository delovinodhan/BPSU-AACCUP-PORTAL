# BPSU CBA Portal Transfer Guide

## Folder model

The staging portal exports or publishes evidence using this structure:

```text
documents/
  bsa/
    area-i-research/
    area-ii-performance-of-graduates/
    area-iii-extension/
    area-iv-internationalization/
    area-v-planning-process/
  bsba/
    area-i-research/
    area-ii-performance-of-graduates/
    area-iii-extension/
    area-iv-internationalization/
    area-v-planning-process/
```

## Controlled document codes

Examples:

- `BPSU-CBA-BSA-L4-AI-0001`
- `BPSU-CBA-BSBA-L4-AV-0001`

The public file name includes its version, for example:

`BPSU-CBA-BSA-L4-AI-0001-v1.pdf`

## Publication governance

A document can be uploaded and reviewed locally without being exposed publicly. **Ready to Publish** is the publication clearance state. It should be used only after the exact version has been checked for confidentiality, personal information, correctness, and appropriateness for external accreditation access.
